# Personal Expense Tracker

Kişisel gelir ve giderlerin güvenli bir şekilde takip edilmesini sağlayan tam kapsamlı (full-stack) web uygulaması.

---

## 🛠️ Teknolojiler

### Backend
- **Go (Golang)** - RESTful API mimarisi
- **PostgreSQL** - İlişkisel veritabanı
- **JWT (JSON Web Tokens)** - Kimlik doğrulama ve oturum yönetimi
- **Bcrypt** - Şifre hashleme ve güvenlik
- **Docker & Docker Compose** - Konteynerleştirme ve yerel geliştirme ortamı

### Frontend
- **React 19 & TypeScript** - Tip güvenli kullanıcı arayüzü
- **Vite** - Hızlı geliştirme ve derleme aracı
- **Tailwind CSS v4** - Modern ve duyarlı (responsive) tasarım
